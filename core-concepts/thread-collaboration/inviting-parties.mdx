---
title: Invite another party
description: Let a partner, supplier or another team record steps on your thread.
---

When another organisation, or a service that doesn't share your API keys, needs
to take part in a thread, invite them. You send them a token; they use it to
join the thread with the role and access you chose.

<CodeGroup>
```javascript JavaScript
const invitation = await thread.inviteParty({
  role: 'logistics',
  accessLevel: Threadify.FOR_EXTERNAL,
  expiresIn: '48h',
});

// Send invitation.token to the other party.
```
```go Go
invitation, err := thread.InviteParty(ctx, threadify.InviteOptions{
    Role:        "logistics",
    AccessLevel: threadify.ForExternal,
    ExpiresIn:   "48h",
})
if err != nil {
    return err
}

// Send invitation.Token to the other party.
```
```python Python
from threadify import Threadify, InviteOptions

invitation = await thread.invite_party(
    InviteOptions(role="logistics", access_level=Threadify.FOR_EXTERNAL, expires_in="48h")
)

# Send invitation.token to the other party.
```
</CodeGroup>

| Option | Default | Meaning |
| --- | --- | --- |
| `role` | required | Their role in the contract, for example `logistics`. It must be one of the contract's parties. |
| `accessLevel` | external | What they can do on the thread. See [access levels](/things-to-know/access-levels#thread-access-levels). |
| `expiresIn` | `24h` | How long the token can be used, up to `7d` |

Access level constants: `FOR_EXTERNAL`, `FOR_PARTICIPANT` and `FOR_OBSERVER` on
`Threadify` in JavaScript and Python; `ForExternal`, `ForParticipant` and
`ForObserver` in Go.

The invitation contains the `token`, `threadId`, `role`, `accessLevel` and
`expiresAt`. Treat the token like a password: anyone who has it can join.
