---
title: Join a thread
description: Join a thread with an invitation token, or by ID from your own services.
---

## With an invitation

The other party connects with their own API key and joins with the token you
sent them. Their role and access level come from the invitation.

<CodeGroup>
```javascript JavaScript
const thread = await connection.join(invitationToken);
```
```go Go
thread, err := conn.Join(ctx, threadify.WithJoinToken(invitationToken))
if err != nil {
    return err
}
```
```python Python
thread = await connection.join(token=invitation_token)
```
</CodeGroup>

## By ID

Your own services can join a thread directly with its ID and a contract role.
They join as a participant.

<CodeGroup>
```javascript JavaScript
const thread = await connection.join(threadId, 'logistics');
```
```go Go
thread, err := conn.Join(ctx,
    threadify.WithJoinThreadID(threadID),
    threadify.WithJoinRole("logistics"),
)
if err != nil {
    return err
}
```
```python Python
thread = await connection.join(thread_id=thread_id, role="logistics")
```
</CodeGroup>

If you know the thread's key, calling
[`connection.thread(key, { role })`](/core-concepts/threads) is usually simpler.

Once joined, record steps as usual. Your role decides which contract steps you
can report, and your access level decides what else you can do and which
notifications you get. See [Roles and access](/things-to-know/access-levels).
