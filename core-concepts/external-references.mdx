title: 'External References'
description: 'Link your workflows to external systems like payment providers, Shopify, and more'
---

References are key/value identifiers—such as an order ID, customer ID or support
ticket—that let you find a thread using names already used by your systems.

### Adding References

<CodeGroup>

```javascript JavaScript
// Add references to an existing thread
await thread.addRefs({
  payment_id: payment.id,
  customer_id: payment.customer,
  order_id: 'ORD-12345'
});

await thread.step('process_payment')
  .addContext({ amount: 299.99, currency: 'USD' })
  .success();
```

```go Go
// Add references to an existing thread
err = thread.AddRefs(ctx, map[string]string{
    "payment_id":   payment.ID,
    "customer_id": payment.Customer,
    "order_id":           "ORD-12345",
})
if err != nil {
    log.Fatal(err)
}

_, err = thread.Step("process_payment").
    AddContext(map[string]any{"amount": 299.99, "currency": "USD"}).
    Success(ctx)
if err != nil {
    log.Fatal(err)
}
```

```python Python
# Add references to an existing thread
await thread.add_refs({
    "payment_id": payment.id,
    "customer_id": payment.customer,
    "order_id": "ORD-12345"
})

await (
    thread.step("process_payment")
    .add_context({"amount": 299.99, "currency": "USD"})
    .success()
)
```

</CodeGroup>

### Querying by Reference

Refs can match multiple threads; they do not enforce uniqueness or merge threads.
JavaScript lookups accept exactly one ref pair, with filters in an optional second
argument. See [Getting Threads](/core-concepts/data-retrieval/getting-threads) for
pagination, return values, and examples.


<CodeGroup>

```javascript JavaScript
const threads = await threadify.getThreadsByRef({
  payment_id: 'pi_1234567890'
});
```

```go Go
threads, err := conn.GetThreadsByRef(ctx, &threadify.RefQuery{
    RefKey:   "payment_id",
    RefValue: "pi_1234567890",
})
if err != nil {
    log.Fatal(err)
}
```

```python Python
from threadify.models import RefQuery

threads = await conn.get_threads_by_ref(
    RefQuery(ref_key="payment_id", ref_value="pi_1234567890")
)
```

</CodeGroup>
