---
title: References
description: Attach your own IDs, such as order or customer IDs, to threads so you can find them later.
---

A reference is a key–value pair, such as `order_id: ORD-12345`, that connects a
thread to the IDs your other systems use. Use references to find threads, and to
group them into [entity profiles](/core-concepts/entity-profiles).

## Add references

Pass `refs` when you [create a thread](/core-concepts/threads), or add them
later:

<CodeGroup>
```javascript JavaScript
await thread.addRefs({
  payment_id: payment.id,
  customer_id: payment.customer,
});
```
```go Go
err := thread.AddRefs(ctx, map[string]string{
    "payment_id":  payment.ID,
    "customer_id": payment.Customer,
})
if err != nil {
    return err
}
```
```python Python
await thread.add_refs({
    "payment_id": payment.id,
    "customer_id": payment.customer,
})
```
</CodeGroup>

Values must be strings. With OpenTelemetry, set `threadify.ref.<key>` on a span,
for example `threadify.ref.customer_id`.

## Find threads by reference

<CodeGroup>
```javascript JavaScript
const threads = await connection.getThreadsByRef({ payment_id: 'pi_1234567890' });
```
```go Go
threads, err := conn.GetThreadsByRef(ctx, map[string]string{"payment_id": "pi_1234567890"})
if err != nil {
    return err
}
```
```python Python
threads = await connection.get_threads_by_ref({"payment_id": "pi_1234567890"})
```
</CodeGroup>

See [Find threads](/core-concepts/data-retrieval/getting-threads) for filters and
pagination.

## References vs. thread keys

A reference doesn't identify a thread. Many threads can share a
`customer_id`, and adding the same reference to two threads doesn't merge them.

To identify one run, use a [thread key](/core-concepts/threads#create-or-resume-a-thread).
`connection.thread(key)` always returns the same thread for the same key, and
`threadify.thread_key` does the same for OpenTelemetry spans.

A good pattern: use the run's own ID as the thread key (`refund:RF-123`), and put
the IDs it relates to in references (`customer_id`, `order_id`).
