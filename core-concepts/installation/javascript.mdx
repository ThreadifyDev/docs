### Installation

<CodeGroup>

```bash npm
npm install @threadify/sdk
```

```bash yarn
yarn add @threadify/sdk
```

```bash pnpm
pnpm add @threadify/sdk
```

</CodeGroup>

### Release Channels

The default installation uses the stable `latest` release. When a prerelease is
available, install the `next` channel explicitly:

```bash
npm install @threadify/sdk@next
```

See the [SDK releases](https://github.com/ThreadifyDev/node-sdk/releases) for
version changes. Both ESM and CommonJS entry points are included in the package.

## Import

<CodeGroup>

```javascript ES Modules (recommended)
import { Threadify } from '@threadify/sdk';
```

```javascript CommonJS
const { Threadify } = require('@threadify/sdk');
```

</CodeGroup>
