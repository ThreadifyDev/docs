---
title: JavaScript
description: Install the Threadify SDK for Node.js, TypeScript and browsers.
---

<CodeGroup>
```bash npm
npm install @threadify/sdk
```
```bash yarn
yarn add @threadify/sdk
```
```bash pnpm
pnpm add @threadify/sdk
```
</CodeGroup>

The package includes ES module and CommonJS builds and TypeScript types:

<CodeGroup>
```javascript ES modules
import { Threadify } from '@threadify/sdk';
```
```javascript CommonJS
const { Threadify } = require('@threadify/sdk');
```
</CodeGroup>

For web pages, import `@threadify/sdk/browser` instead. See
[Browser SDK](/core-concepts/browser).

To try a prerelease, install the `next` tag: `npm install @threadify/sdk@next`.
Changes are listed in the [SDK releases](https://github.com/ThreadifyDev/node-sdk/releases).
