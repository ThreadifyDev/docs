---
title: Go
description: Install the Threadify SDK for Go.
---

Requires Go 1.25 or later.

```bash
go get github.com/ThreadifyDev/go-sdk
```

```go
import threadify "github.com/ThreadifyDev/go-sdk"
```

The OpenTelemetry exporter is a separate module:

```bash
go get github.com/ThreadifyDev/go-sdk/otel
```

```go
import threadifyotel "github.com/ThreadifyDev/go-sdk/otel"
```

## Things that work differently in Go

- Every call that talks to the Engine takes a `context.Context`. Cancelling it
  cancels the call, including [waits](/core-concepts/execution-waits).
- Timeouts are `time.Duration` values.
- Errors from the Engine keep the request's identifiers (such as the step or
  invocation ID), so you can [recover](/core-concepts/execution-waits#recovery)
  without reporting twice.
- Connection options are functional options: `WithEngineURL`,
  `WithServiceName`, `WithMaxInFlight`, `WithConnectTimeout`,
  `WithRequestTimeout`, `WithDebug` and `WithLogger`.
