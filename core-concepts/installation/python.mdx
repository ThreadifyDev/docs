Requires Python 3.10 or later.

<CodeGroup>
```bash pip
pip install threadify-sdk
```
```bash uv
uv pip install threadify-sdk
```
</CodeGroup>

For the OpenTelemetry exporter, install the extra:

```bash
pip install 'threadify-sdk[otel]'
```

```python
from threadify import Threadify
```

## Things that work differently in Python

- The SDK is async. Call it from an `asyncio` event loop and `await` each call.
- Names use snake case: `add_context`, `wait_for`, `service_name`.
- Timeouts are in seconds.
- To cancel a [wait](/core-concepts/execution-waits), cancel its task.
- To cancel a thread, call `thread.close()`. (`complete()` completes it.)
