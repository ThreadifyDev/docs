---
title: Linked threads
description: Link related threads, such as a parent order and its shipments, and read them as a chain.
---

Keep each thread focused on one run, and link threads that belong together, for
example an order and the shipment threads it starts.

## Link a thread

Call `linkThread` on the child, passing the parent's ID:

<CodeGroup>
```javascript JavaScript
const shipment = await connection.thread(`shipment:${shipmentId}`);
await shipment.linkThread(order.id, 'parent');
```
```go Go
shipment, err := conn.Thread(ctx, "shipment:"+shipmentID)
if err != nil {
    return err
}
err = shipment.LinkThread(ctx, order.ThreadID, "parent")
```
```python Python
shipment = await connection.thread(f"shipment:{shipment_id}")
await shipment.link_thread(order.thread_id, "parent")
```
</CodeGroup>

The second argument names the relationship. It defaults to `parent`; any short
label such as `followup` or `related` works.

## Read a chain

Start from any thread and get it plus everything linked below it:

<CodeGroup>
```javascript JavaScript
const chain = await connection.getThreadChain(order.id, 3);
```
```go Go
chain, err := conn.GetThreadChain(ctx, order.ThreadID, 3)
if err != nil {
    return err
}
for _, t := range chain {
    fmt.Println(t.ID, t.Status)
}
```
```python Python
chain = await connection.get_thread_chain(order.thread_id, max_depth=3)
for t in chain:
    print(t.id, t.status)
```
</CodeGroup>

- The result starts with the thread you passed, followed by linked threads,
  nearest first.
- The second argument is how many levels to follow. The default is 3.
- Chains only go downward, from parent to children.
- Loops are detected and followed only once.
- New links can take a few seconds to appear.
