---
title: Find threads
description: Look up recorded threads by ID or by reference.
---

These calls read a thread's stored history. They return a read-only copy you
can inspect; to add steps, use
[`connection.thread(key)`](/core-concepts/threads) or
[join the thread](/core-concepts/thread-collaboration/joining-threads).

New activity can take a few seconds to appear.

## By ID

<CodeGroup>
```javascript JavaScript
const archived = await connection.getThread(threadId);
console.log(archived.status, archived.contractName);
```
```go Go
archived, err := conn.GetThread(ctx, threadID)
if err != nil {
    return err
}
fmt.Println(archived.Status, archived.ContractName)
```
```python Python
archived = await connection.get_thread(thread_id)
print(archived.status, archived.contract_name)
```
</CodeGroup>

To read back a thread you're working on, pass its ID: `thread.id` in JavaScript,
`thread.ThreadID` in Go, `thread.thread_id` in Python.

## By reference

Pass exactly one reference key and value:

<CodeGroup>
```javascript JavaScript
const threads = await connection.getThreadsByRef({ order_id: 'ORD-1001' });

// With filters and pagination
const completed = await connection.getThreadsByRef(
  { order_id: 'ORD-1001' },
  { status: 'completed', limit: 10, offset: 0 },
);

// Just the first match, or null
const first = await connection.getThreadByRef({ order_id: 'ORD-1001' });
```
```go Go
threads, err := conn.GetThreadsByRef(ctx, map[string]string{"order_id": "ORD-1001"})

// With filters and pagination
completed, err := conn.GetThreadsByRef(ctx,
    map[string]string{"order_id": "ORD-1001"},
    threadify.RefQuery{Status: "completed", Limit: 10},
)

// Just the first match, or nil
first, err := conn.GetThreadByRef(ctx, map[string]string{"order_id": "ORD-1001"})
```
```python Python
threads = await connection.get_threads_by_ref({"order_id": "ORD-1001"})

# With filters and pagination
completed = await connection.get_threads_by_ref(
    {"order_id": "ORD-1001"}, status="completed", limit=10,
)

# Just the first match, or None
first = await connection.get_thread_by_ref({"order_id": "ORD-1001"})
```
</CodeGroup>

The result is a list, empty if nothing matches. Many threads can share a
reference, so expect more than one.

| Filter | Meaning |
| --- | --- |
| `status` | `active`, `completed` or `cancelled` |
| `startedAfter`, `startedBefore` | ISO 8601 timestamps |
| `limit` | Page size. Default 50, maximum 100. |
| `offset` | Number of results to skip |

In Go these are `RefQuery` fields (`Status`, `StartedAfter`, …). In Python
they're keyword arguments (`status`, `started_after`, …).

## What you get back

| Field | Meaning |
| --- | --- |
| `id` | Thread ID |
| `status` | `active`, `completed` or `cancelled` |
| `contractName`, `contractVersion` | The contract, if any |
| `refs` | The thread's references |
| `startedAt`, `completedAt` | ISO 8601 timestamps |
| `ownerId` | The user or service that created it |
| `error` | Error message, if the thread failed |

From here you can read its [steps](/core-concepts/data-retrieval/querying-steps)
and [validation results](/core-concepts/data-retrieval/validation-results).
