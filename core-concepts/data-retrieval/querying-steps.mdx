---
title: Read steps
description: Read a recorded thread's steps, each step's attempts, and its sub-steps.
---

Start from a recorded thread (see [Find threads](/core-concepts/data-retrieval/getting-threads)):

<CodeGroup>
```javascript JavaScript
const archived = await connection.getThread(threadId);

const steps = await archived.steps();                                 // all steps
const payments = await archived.steps('payment_processed');           // one step name
const failed = await archived.steps('payment_processed', { status: 'failed' });
```
```go Go
archived, err := conn.GetThread(ctx, threadID)
if err != nil {
    return err
}

// Steps(ctx, stepName, idempotencyKey, status); "" means any
steps, err := archived.Steps(ctx, "", "", "")
payments, err := archived.Steps(ctx, "payment_processed", "", "")
failed, err := archived.Steps(ctx, "payment_processed", "", "failed")
```
```python Python
archived = await connection.get_thread(thread_id)

steps = await archived.steps()
payments = await archived.steps(step_name="payment_processed")
failed = await archived.steps(step_name="payment_processed", status="failed")
```
</CodeGroup>

`status` is `success`, `failed` or `error`.

Each step has:

| Field | Meaning |
| --- | --- |
| `stepName` | The step's name |
| `status` | Its latest outcome |
| `idempotencyKey` | The key the report was recorded under |
| `retryCount` | How many times it was retried |
| `firstSeenAt`, `lastUpdatedAt` | ISO 8601 timestamps |
| `previousStep` | The step recorded before it |
| `verified` | Whether its [integrity check](/things-to-know/hash-chain) passed |

## Every attempt at a step

A step's history lists each report, including retries:

<CodeGroup>
```javascript JavaScript
const [step] = await archived.steps('payment_processed');
const history = await step.history({ limit: 100 });
```
```go Go
history, err := steps[0].History(ctx, &threadify.HistoryQueryOptions{Limit: 100})
```
```python Python
from threadify import HistoryQueryOptions

history = await steps[0].history(HistoryQueryOptions(limit=100))
```
</CodeGroup>

| Field | Meaning |
| --- | --- |
| `attempt` | Attempt number |
| `status` | Outcome of that attempt |
| `timestamp` | When it was recorded |
| `duration` | How long it took, in milliseconds |
| `context` | The context sent with it, as JSON |
| `error` | Error message, if it failed |
| `actor`, `actorService` | Who reported it |

You can also filter history by `startAt`, `endAt`, `activityType` and `actor`.

## Sub-steps

<CodeGroup>
```javascript JavaScript
const subSteps = await step.subSteps();
```
```go Go
subSteps, err := steps[0].SubSteps(ctx)
```
```python Python
sub_steps = await steps[0].sub_steps()
```
</CodeGroup>

Each sub-step has a `name`, `status`, `payload` and `recordedAt`.
