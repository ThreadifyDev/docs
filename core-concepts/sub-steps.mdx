---
title: Sub-steps
description: Record the smaller operations inside a step, such as checks and calls to other services.
---

A sub-step records part of a larger step: the card check inside a payment, or
each API call an agent makes during one tool call. Sub-steps show up under their
step in the dashboard. They help you see where time went and what failed.

Add sub-steps before you report the step's outcome. They're sent with it.

<CodeGroup>
```javascript JavaScript
const payment = thread.step('payment_processed');

try {
  payment.subStep('validate_card', { cardType: 'visa' });
  payment.subStep('check_fraud', { fraudScore: 0.15 });
  payment.subStep('authorize', { authCode: 'AUTH-123' });

  await payment.addContext({ amount: 299.99 }).success();
} catch (error) {
  payment.subStep('error', { error: error.message }, 'failed');
  await payment.failed('Payment failed');
}
```
```go Go
payment := thread.Step("payment_processed")

if err := processPayment(); err != nil {
    payment.SubStep("error", map[string]any{"error": err.Error()}, "failed")
    if _, stepErr := payment.Failed(ctx, "Payment failed"); stepErr != nil {
        return stepErr
    }
    return err
}

payment.SubStep("validate_card", map[string]any{"cardType": "visa"})
payment.SubStep("check_fraud", map[string]any{"fraudScore": 0.15})
payment.SubStep("authorize", map[string]any{"authCode": "AUTH-123"})

if _, err := payment.AddContext(map[string]any{"amount": 299.99}).Success(ctx); err != nil {
    return err
}
```
```python Python
payment = thread.step("payment_processed")

try:
    payment.sub_step("validate_card", {"cardType": "visa"})
    payment.sub_step("check_fraud", {"fraudScore": 0.15})
    payment.sub_step("authorize", {"authCode": "AUTH-123"})

    await payment.add_context({"amount": 299.99}).success()
except Exception as error:
    payment.sub_step("error", {"error": str(error)}, "failed")
    await payment.failed("Payment failed")
```
</CodeGroup>

`subStep(name, data?, status?)` takes a name, optional data, and a status of
`success` (the default) or `failed`.

Contracts don't check sub-steps, and sub-steps don't trigger notifications. If
something needs a rule or an alert, make it a step.

With OpenTelemetry, span events become sub-steps automatically.
