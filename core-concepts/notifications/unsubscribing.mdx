---
title: Unsubscribe
description: Stop receiving an event.
---

<CodeGroup>
```javascript JavaScript
connection.unsubscribe('step.success', 'order_placed');
connection.unsubscribe('thread.completed');
```
```go Go
err := conn.Unsubscribe(ctx, "step.success", "order_placed")
err = conn.Unsubscribe(ctx, "thread.completed", "")
```
```python Python
connection.unsubscribe("step.success", "order_placed")
connection.unsubscribe("thread.completed")
```
</CodeGroup>

This removes your handlers for that event and step, and the Engine stops sending
it. Calling it again, or for something you never subscribed to, does nothing.

Closing the connection removes all subscriptions.
