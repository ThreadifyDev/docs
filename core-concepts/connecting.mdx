### Basic Connection

<CodeGroup>

```javascript JavaScript
import { Threadify } from '@threadify/sdk';

const threadify = await Threadify.connect('your-api-key', 'my-service', {
  engineUrl: 'https://threadify.example.com'
});
await threadify.close()
```

```go Go
ctx := context.Background()
conn, err := threadify.Connect(ctx, "your-api-key", 
    threadify.WithServiceName("my-service"),
    threadify.WithEngineURL("https://threadify.example.com"),
)
if err != nil {
    log.Fatal(err)
}
defer conn.Close()
```

```python Python
from threadify import Threadify

# Connect with your API key and service name
connection = await Threadify.connect(
    "your-api-key",
    service_name="my-service",
    engine_url="https://threadify.example.com",
)
```

</CodeGroup>

### One Engine URL

Copy the address from **Settings → Engine** into JavaScript `engineUrl`, Go
`WithEngineURL`, or Python `engine_url`. The SDK handles
WebSocket and GraphQL routing internally; no separate paths are needed. A
reverse-proxy prefix such as `https://example.com/threadify` is preserved.
`Threadify.create({ apiKey, serviceName, engineUrl })` also accepts this option.
Do not combine `engineUrl` with explicit `url`, `wsUrl` or `graphqlUrl` options.
OpenTelemetry and MCP clients have their own collapsible setup sections in Settings.

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `apiKey` | string | Yes | Your Threadify API key |
| `serviceName` | string | No | Service identifier (e.g., 'payment-service') |
| `options` | object | No | Connection options |

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `maxInFlight` | number | 10 | Max pending notifications (max: 100) |
| `engineUrl` | string | Set explicitly | Your Engine base URL for both writes and queries |
| `reconnect` | boolean | true | Auto-reconnect on disconnect |
| `timeout` | number | 30000 | Connection timeout (ms) |

<Warning>
Never commit API keys to version control. Use environment variables or secret managers/vault.
</Warning>
