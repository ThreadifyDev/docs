---
title: Connect
description: Open a connection to your Engine from the SDK.
---

<CodeGroup>
```javascript JavaScript
import { Threadify } from '@threadify/sdk';

const connection = await Threadify.connect(process.env.THREADIFY_API_KEY, 'payment-service', {
  engineUrl: 'https://threadify.example.com',
});

// When your process shuts down
await connection.close();
```
```go Go
conn, err := threadify.Connect(ctx, os.Getenv("THREADIFY_API_KEY"),
    threadify.WithServiceName("payment-service"),
    threadify.WithEngineURL("https://threadify.example.com"),
)
if err != nil {
    log.Fatal(err)
}
defer conn.Close()
```
```python Python
import os
from threadify import Threadify

connection = await Threadify.connect(
    os.environ["THREADIFY_API_KEY"],
    service_name="payment-service",
    engine_url="https://threadify.example.com",
)

# When your process shuts down
await connection.close()
```
</CodeGroup>

One connection can handle many threads. Open it once when your service starts
and reuse it.

- **API key:** an [Engine API key](/authentication#create-an-api-key). Load it
  from an environment variable or secret manager; never commit it.
- **Service name:** identifies your service in the dashboard, for example
  `payment-service`. Optional, but recommended.
- **Engine URL:** the address from **Settings → Engine**. The SDK works out the
  WebSocket and GraphQL addresses from it. If your Engine is behind a path, such
  as `https://example.com/threadify`, include the path.

## Options

| JavaScript | Go | Python | Default | Meaning |
| --- | --- | --- | --- | --- |
| `engineUrl` | `WithEngineURL` | `engine_url` | none | Your Engine's address |
| `maxInFlight` | `WithMaxInFlight` | `max_in_flight` | 10 | How many [notifications](/core-concepts/notifications/subscribing) can be waiting for your acknowledgement at once (1–100) |
| `debug` | `WithDebug` | `debug` | `false` | Log protocol messages |
| — | `WithConnectTimeout` | `connect_timeout` | 10 s | How long to wait for the connection to open. In JavaScript this is fixed at 10 seconds. |
| — | `WithRequestTimeout` | — | 1 s | Default timeout for each call to the Engine |

`Threadify.create({ apiKey, serviceName, engineUrl }).connect()` is equivalent
in JavaScript.
