---
title: Idempotency
description: Ensuring consistent step recordings in Threadify
---

Idempotency prevents retries from recording the same step more than once.

### Idempotency Approaches

| Approach | When to Use | Key Generation |
|----------|-------------|----------------|
| **Auto-generated** (default) | Context uniquely identifies operation | Hash of `stepName + context` |
| **Manual** (`.idempotencyKey()`) | External system IDs, user-initiated retries, cross-service deduplication | Custom key (e.g., payment providers payment ID, request ID) |

<CodeGroup>

```javascript JavaScript
// Auto-generated (default)
await thread.step('validate_cart')
  .addContext({ items: '3', total: '99.99' })
  .success();

// Manual key with external ID
const payment = await payments.charges.create({ amount: 9999 });
await thread.step('charge_payment')
  .idempotencyKey(payment.id)
  .addContext({ amount: '99.99' })
  .success();
```

```go Go
// Auto-generated (default)
_, err := thread.Step("validate_cart").
    AddContext(map[string]any{"items": "3", "total": "99.99"}).
    Success(ctx)
if err != nil {
    log.Fatal(err)
}

// Manual key with external ID
payment, err := payments.Charges.Create(&payments.ChargeParams{Amount: 9999})
if err != nil {
    log.Fatal(err)
}
_, err = thread.Step("charge_payment").
    IdempotencyKey(payment.ID).
    AddContext(map[string]any{"amount": "99.99"}).
    Success(ctx)
if err != nil {
    log.Fatal(err)
}
```

```python Python
# Auto-generated (default)
await (
    thread.step("validate_cart")
    .add_context({"items": "3", "total": "99.99"})
    .success()
)

# Manual key with external ID
payment = await payments.charges.create(amount=9999)
await (
    thread.step("charge_payment")
    .idempotency_key(payment.id)
    .add_context({"amount": "99.99"})
    .success()
)
```

</CodeGroup>

### Best Practices

- Use a stable business identifier, such as an order or payment ID, for retries.
- Never reuse a key for a different operation.
