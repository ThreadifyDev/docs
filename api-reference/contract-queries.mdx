---
title: Contract queries
description: Read the compiled structure of a contract version.
---

```graphql
query {
  contractGraph(name: "refund_review", version: 1) {
    graph {
      nodes {
        id
        owner
        dependsOn
        next
        timeout
        businessContext
      }
      entryPoints
      terminalSteps
    }
    transitions {
      from
      to
      timeout
      maxRetries
    }
    parties
  }
}
```

Leave out `version` for the latest.

| Field | Meaning |
| --- | --- |
| `graph.nodes` | The steps and groups (below) |
| `graph.entryPoints` | Steps a thread can start with |
| `graph.terminalSteps` | Steps that complete the thread |
| `transitions` | Allowed moves: `from`, `to`, `timeout`, `maxRetries` |
| `validation` | Thread-wide rules: `maxDuration`, `allowMultipleTerminals`, `multipleTerminalsSeverity` |
| `parties` | The contract's roles |

## Node fields

| Field | Meaning |
| --- | --- |
| `id` | Step or group name |
| `type` | Node type, such as `step` or `parallel_group` |
| `owner` | The role that reports it |
| `mode` | Step type, such as `managed` |
| `required` | Whether it's required |
| `dependsOn` | Steps that must have succeeded first |
| `next` | Steps allowed immediately after |
| `steps` | A group's members |
| `parentGroup` | The group a step belongs to |
| `timeout`, `maxDuration` | Time limits |
| `businessContext` | Its required and optional context fields |
