---
title: Step queries
description: Read a thread's steps, every attempt at a step, and its sub-steps.
---

## A thread's steps

```graphql
query {
  thread(id: "THREAD_ID") {
    steps(stepName: "payment_processed") {
      stepName
      status
      retryCount
      latestContext
      subSteps {
        name
        status
        payload
      }
    }
  }
}
```

`steps` accepts `stepName`, `idempotencyKey` and `status`, all optional.

| Field | Meaning |
| --- | --- |
| `stepName` | The step's name |
| `idempotencyKey` | The key the report was recorded under |
| `status` | Latest outcome: `success`, `failed` or `error` |
| `retryCount` | Number of retries |
| `firstSeenAt`, `lastUpdatedAt` | ISO 8601 timestamps |
| `startedAt`, `finishedAt` | When the latest attempt ran |
| `previousStep` | The step recorded before it |
| `actor`, `actorService` | Who reported the latest attempt |
| `latestContext` | The latest attempt's context, as JSON |
| `history(...)` | Every attempt (below) |
| `subSteps` | Its sub-steps |
| `hash`, `prevHash`, `verified` | [Integrity](/api-reference/integrity-verification) |

## Every attempt at a step

```graphql
query {
  stepHistory(threadId: "THREAD_ID", stepName: "payment_processed", limit: 100) {
    attempt
    timestamp
    status
    duration
    actor
    error
  }
}
```

| Argument | Meaning |
| --- | --- |
| `threadId`, `stepName` | Required |
| `idempotencyKey` | One particular report |
| `startAt`, `endAt` | ISO 8601 timestamps |
| `activityType`, `actor` | Filters |
| `limit` | Default 100, maximum 1,000 |
| `offset` | Results to skip |

| Field | Meaning |
| --- | --- |
| `attempt` | Attempt number |
| `timestamp` | When it was recorded |
| `status` | Outcome |
| `duration` | Milliseconds |
| `startedAt`, `finishedAt` | ISO 8601 timestamps |
| `context` | Context, as JSON |
| `error` | Error message, if any |
| `actor`, `actorService` | Who reported it |
| `hash`, `prevHash` | Integrity chain values |

## Sub-step fields

| Field | Meaning |
| --- | --- |
| `id` | Sub-step ID |
| `name` | Name |
| `status` | `success` or `failed` |
| `payload` | Data, as JSON |
| `recordedAt` | ISO 8601 timestamp |
