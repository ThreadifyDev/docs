---
title: Integrity queries
description: Verify a thread's or a step's recorded history from code.
---

## A whole thread

```graphql
query {
  verifyThreadIntegrity(threadId: "THREAD_ID") {
    verified
    totalEvents
    brokenAt
    error
    lastVerifiedAt
  }
}
```

If `verified` is `false`, `brokenAt` says where the chain stops matching.

## One step

```graphql
query {
  verifyStepIntegrity(threadId: "THREAD_ID", stepName: "refund", idempotencyKey: "KEY") {
    verified
    hash
    prevHash
    error
  }
}
```

All three arguments are required. Get the idempotency key from the thread's
[steps](/api-reference/step-queries).

## While reading a thread

```graphql
query {
  thread(id: "THREAD_ID") {
    lastHash
    hashChainVerified
    steps {
      stepName
      hash
      prevHash
      verified
    }
  }
}
```

Verification is only computed for the fields you ask for. For what a result
means, see [Integrity verification](/things-to-know/hash-chain).
