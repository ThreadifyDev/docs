---
title: Thread queries
description: Fetch one thread, search threads, and find threads by contract or reference.
---

## One thread

```graphql
query {
  thread(id: "THREAD_ID") {
    id
    label
    status
    contractName
    contractVersion
    refs
    tags
    startedAt
    completedAt
    steps {
      stepName
      status
    }
  }
}
```

## Search

```graphql
query {
  threads(contractName: "refund_review", status: "completed", limit: 50) {
    totalCount
    threads {
      id
      status
      startedAt
    }
  }
}
```

| Argument | Meaning |
| --- | --- |
| `contractName`, `contractVersion` | The contract |
| `status` | `active`, `completed` or `cancelled` |
| `actor` | A user or service that recorded steps |
| `tags` | Threads that have all of these tags |
| `startedAfter`, `startedBefore`, `completedAfter`, `completedBefore` | ISO 8601 timestamps |
| `limit` | Default 50, maximum 100 |
| `offset` | Results to skip |

`threadsByContract(contractName, ...)` takes the same filters, minus the
completion dates, with `contractName` required.

## By reference

```graphql
query {
  threadsByRef(refKey: "order_id", refValue: "ORD-12345") {
    totalCount
    threads {
      id
      refs
    }
  }
}
```

- `refValue` matches part of a value, ignoring case: `"ABC"` finds `cus_ABC123`.
- Leave out `refKey` to search every reference key. This helps when you have an
  ID but don't know what it's called, for example in support.
- Also accepts `status`, `startedAfter`, `startedBefore`, `limit` and `offset`.

## Linked threads

```graphql
query {
  threadChain(rootId: "THREAD_ID", maxDepth: 3) {
    id
    label
    status
  }
}
```

See [Linked threads](/core-concepts/data-retrieval/thread-chains).

## Thread fields

| Field | Meaning |
| --- | --- |
| `id` | Thread ID |
| `label` | Display name |
| `status` | `active`, `completed` or `cancelled` |
| `contractId`, `contractName`, `contractVersion` | Its contract, if any |
| `refs` | References, as JSON |
| `tags` | Tags set when it was created |
| `ownerId`, `createdBy` | Who created it |
| `startedAt`, `completedAt` | ISO 8601 timestamps |
| `error` | Error message, if it failed |
| `steps(stepName, idempotencyKey, status)` | Its [steps](/api-reference/step-queries) |
| `validationResults(options)` | Its [validation results](/api-reference/validation-queries) |
| `notificationSummary`, `notifications(options)` | Its notifications |
| `threadChain(maxDepth)` | Linked threads |
| `lastHash`, `hashChainVerified`, `hashChainStatus` | [Integrity](/api-reference/integrity-verification) |
