## Before you start

[Run your Engine](/self-hosting), sign in, and create an API key under
**Developer → API Keys**. Use your Engine's address in the examples below.

## 1. Install the SDK

<Tabs>
<Tab title="JavaScript">
```bash
npm install @threadify/sdk
```
</Tab>
<Tab title="Go">
```bash
go get github.com/ThreadifyDev/go-sdk
```
</Tab>
<Tab title="Python">
```bash
pip install threadify-sdk
```
</Tab>
</Tabs>

## 2. Connect to Threadify

<Tabs>
<Tab title="JavaScript">
```javascript
import { Threadify } from '@threadify/sdk';

// Connect with your API key and service name
const connection = await Threadify.connect('your-api-key', 'my-service', {
  engineUrl: 'https://threadify.example.com' // Your Settings → Engine address
});
```
</Tab>
<Tab title="Go">
```go
ctx := context.Background()
conn, err := threadify.Connect(ctx, "your-api-key", 
    threadify.WithServiceName("my-service"),
    threadify.WithEngineURL("https://threadify.example.com"),
)
if err != nil {
    log.Fatal(err)
}
defer conn.Close()
```
</Tab>
<Tab title="Python">
```python
from threadify import Threadify

# Connect with your API key and service name
connection = await Threadify.connect(
    "your-api-key",
    service_name="my-service",
    engine_url="https://threadify.example.com",
)
```
</Tab>
</Tabs>

## 3. Create or Resume Your Thread

<Tabs>
<Tab title="JavaScript">
```javascript
// Use an application order ID as the key, with a human-readable label
const thread = await connection.thread('order:ORD-123', { label: 'Order ORD-123' });

```
</Tab>
<Tab title="Go">
```go
// Use an application order ID as the key, with a human-readable label
thread, err := conn.Thread(ctx, "order:ORD-123", threadify.ThreadOptions{Label: "Order ORD-123"})
if err != nil {
    log.Fatal(err)
}

```
</Tab>
<Tab title="Python">
```python
# Use an application order ID as the key, with a human-readable label
thread = await connection.thread("order:ORD-123", {"label": "Order ORD-123"})

```
</Tab>
</Tabs>

Reuse this key in later requests to recover the same active thread; the optional
object is only needed to provide creation defaults. Threadify manages its internal
ID. A closed thread cannot accept more steps, so choose a fresh key for each new
order. See [threads and steps](/core-concepts/threads) for contracted sessions and
examples in all three SDKs.

## 4. Add Steps to Your Process

<Tabs>
<Tab title="JavaScript">
```javascript
// Create step first, then call methods on it
const step = thread.step('validate_input');
await step.addContext({ userId: 'user-123' }).success();

// Or chain directly on the step builder
await thread.step('process_data')
  .addContext({ records: 42 })
  .success();
```
</Tab>
<Tab title="Go">
```go
// Create step first, then call methods on it
step := thread.Step("validate_input")
_, err = step.AddContext(map[string]any{"userId": "user-123"}).Success(ctx)
if err != nil {
    log.Fatal(err)
}

// Or chain directly on the step builder
_, err = thread.Step("process_data").
    AddContext(map[string]any{"records": 42}).
    Success(ctx)
if err != nil {
    log.Fatal(err)
}
```
</Tab>
<Tab title="Python">
```python
# Create step first, then call methods on it
step = thread.step("validate_input")
await step.add_context({"userId": "user-123"}).success()

# Or chain directly on the step builder
await (
    thread.step("process_data")
    .add_context({"records": 42})
    .success()
)
```
</Tab>
</Tabs>

## 5. Finish and inspect

This example created a free-form thread. Finish it explicitly:

<CodeGroup>
```javascript JavaScript
await thread.complete('Finished');
await connection.close();
```
```go Go
_, err = thread.Complete(ctx, "Finished")
if err != nil { log.Fatal(err) }
```
```python Python
await thread.complete("Finished")
await connection.close()
```
</CodeGroup>

Open **Threads** in your Engine dashboard. Archived views can take a short time
to catch up with accepted events. Next, add a contract and an explicit wait when
your code must check permission before acting.
