---
title: Quick start
description: Connect an SDK to your Engine and record your first thread.
---

You need a running Engine and an API key. If you don't have them yet,
[run the Engine](/self-hosting), sign in, and create a key under
**Developer → API Keys**. Copy your Engine's address from **Settings → Engine**.

## 1. Install the SDK

<CodeGroup>
```bash JavaScript
npm install @threadify/sdk
```
```bash Go
go get github.com/ThreadifyDev/go-sdk
```
```bash Python
pip install threadify-sdk
```
</CodeGroup>

## 2. Connect

<CodeGroup>
```javascript JavaScript
import { Threadify } from '@threadify/sdk';

const connection = await Threadify.connect(process.env.THREADIFY_API_KEY, 'order-service', {
  engineUrl: 'https://threadify.example.com',
});
```
```go Go
conn, err := threadify.Connect(ctx, os.Getenv("THREADIFY_API_KEY"),
    threadify.WithServiceName("order-service"),
    threadify.WithEngineURL("https://threadify.example.com"),
)
if err != nil {
    log.Fatal(err)
}
defer conn.Close()
```
```python Python
import os
from threadify import Threadify

connection = await Threadify.connect(
    os.environ["THREADIFY_API_KEY"],
    service_name="order-service",
    engine_url="https://threadify.example.com",
)
```
</CodeGroup>

## 3. Open a thread

A thread is identified by a key you choose, usually an ID your application
already has. Calling `thread()` with the same key later returns the same thread.

<CodeGroup>
```javascript JavaScript
const thread = await connection.thread('order:ORD-123', { label: 'Order ORD-123' });
```
```go Go
thread, err := conn.Thread(ctx, "order:ORD-123", threadify.ThreadOptions{Label: "Order ORD-123"})
if err != nil {
    log.Fatal(err)
}
```
```python Python
thread = await connection.thread("order:ORD-123", {"label": "Order ORD-123"})
```
</CodeGroup>

## 4. Record steps

<CodeGroup>
```javascript JavaScript
await thread.step('order_received').addContext({ items: 2 }).success();
await thread.step('payment_taken').addContext({ amount: 42.5, currency: 'GBP' }).success();
```
```go Go
if _, err := thread.Step("order_received").AddContext(map[string]any{"items": 2}).Success(ctx); err != nil {
    log.Fatal(err)
}
if _, err := thread.Step("payment_taken").AddContext(map[string]any{"amount": 42.5, "currency": "GBP"}).Success(ctx); err != nil {
    log.Fatal(err)
}
```
```python Python
await thread.step("order_received").add_context({"items": 2}).success()
await thread.step("payment_taken").add_context({"amount": 42.5, "currency": "GBP"}).success()
```
</CodeGroup>

## 5. Finish the thread

This thread has no contract, so you close it yourself:

<CodeGroup>
```javascript JavaScript
await thread.complete('Order fulfilled');
await connection.close();
```
```go Go
if _, err := thread.Complete(ctx, "Order fulfilled"); err != nil {
    log.Fatal(err)
}
```
```python Python
await thread.complete("Order fulfilled")
await connection.close()
```
</CodeGroup>

Open **Threads** in the dashboard to see it. New activity can take a few seconds
to appear.
